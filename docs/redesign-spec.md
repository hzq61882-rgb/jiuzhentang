# 久真堂 · 改版规格（redesign-preview）

## 0. Brief
为久真堂官网做整站视觉改版（内容不变，全部文字仍来自 `tools/content.js`）。
访客：多数用手机访问的学员、患者与同道；需要一眼看出“传承有序、医道本真”。
气质三词：**宣纸 · 墨色 · 守中**（克制、典雅、有呼吸感）。
签名（全站只记住这一个）：**“中气为本、一气周流”** —— 首屏一枚墨线圆（一气周流）缓缓画成，一根金针自上而下落入圆心（中气为本），落点泛起一圈涟漪。
保真：不新增事实、数字、证言、疗效；不新增栏目；占位【…】原样保留。

## 1. Stack
纯静态 HTML/CSS/JS，GitHub Pages。`tools/build.js` 生成 `index.html` 与 `xueguang.html`。
GSAP 3.12.5 + ScrollTrigger 本地托管于 `js/vendor/`（国内访问不依赖外网 CDN）。无构建步骤。

## 2. 字体
| 角色 | 字体 | 字重 | 用途 |
|---|---|---|---|
| 品牌题字 | Ma Shan Zheng（回退 STKaiti/KaiTi） | 400 | 仅首屏“久真堂”与“融”字 |
| 正文/标题 | Noto Serif SC（回退 Songti SC/STSong/SimSun） | 400/600/900 | 全站 |
| 西文小字 | Cormorant Garamond italic | 400 | 英文副题 |
加载：Google Fonts 非阻塞（media=print onload），失败时用系统宋体/楷体。取消 Noto Sans SC，少加载一套字体。

## 3. 色彩
```
--paper #f3eee4  宣纸底（首屏与多数栏目）
--paper2 #ebe3d3 次级纸色（交替栏目）
--ink #1d1a16    墨（正文 100%）
--ink-2 rgba(29,26,22,.74) 次级文字
--mute #6a6155   说明文字（纸底对比度 ≈5.6:1）
--line rgba(29,26,22,.14) 细线
--cinnabar #9b2d20 朱砂：仅用于 主按钮底色 / 印章 / 当前导航点
--gold #a8813a   金：仅用于金针线条
--night #16130f  夜墨：九针、联系、页脚三处深色段落，形成“纸—墨—纸”的节奏
```
禁用：紫色渐变、发光球、厚重投影、渐变文字。

## 4. 版式与组件
- 首屏（100svh）：桌面三分构图——右侧竖排巨字“久真堂”（clamp(110px,12vw,200px)，竖排 vertical-rl），中部墨圆+金针，左下为标语“雪岭守一针，金针济天下”（clamp(26px,2.6vw,40px)/600）、副句、两个按钮；底部三层水墨山脊（SVG 渐变填充，非位图）。手机：竖排题字在右上，墨圆居左上，文字与按钮落在下方三分之一。
- 栏目标题：h2 宋体 600，clamp(30px,4vw,52px)，字距 .08em；英文副题置于标题之后（Cormorant italic 15px，muted），不再放在标题上方。
- 不用“卡片堆叠”：双脉、养生、专长、课程都改为细线分隔的版面（hairline 1px --line），像古籍版心。
- 九针：深色段落，3×3 细线格，每格一根金针线描；点击仍弹出《灵枢》原文。
- 传承：左侧年代列 + 右侧内容的编年表，一条细竖线贯穿。
- 按钮：主按钮朱砂实底 + 纸色字，次按钮墨色细框；圆角 2px（古朴，不用胶囊）。触控高度 ≥ 44px。
- 纸纹：一张 160×160 的灰度噪点 PNG 平铺，透明度 .35 正片叠底，仅在纸色区域。

## 5. 动效
- 首屏时间线（GSAP，总长约 1.9s）：墨圆描边 0→100%（1.5s, power2.inOut, 从 0s）；金针 y:-60%→0 + opacity（0.9s, expo.out, 0.35s）；涟漪 scale .2→1.6、opacity .8→0（1.1s, 1.1s）；题字逐字 y:30, blur 8px→0（0.9s, stagger .12, 0.2s）；标语/副句/按钮依次上浮（0.8s, stagger .1, 0.7s）。
- 滚动：首屏墨圆随滚动轻转 24°、金针淡出（scrub，lerp 由 ScrollTrigger scrub:0.6）。
- “堂史”正文：随滚动逐字由 18% 透明度变为 100%（scroll-linked char reveal）。
- 其余栏目：进入视口一次性上浮 24px + 淡入（0.8s, cubic-bezier(.22,1,.36,1)，stagger 80ms）。
- `prefers-reduced-motion: reduce`：全部直接显示终态，无滚动联动。JS 失败时所有文字默认可见。

## 6. 手机
- 导航：汉堡按钮 → 全屏纸色菜单，链接逐个上浮（50ms 错开），点链接/Esc/改尺寸即关闭，并锁定页面滚动。
- 字号用 clamp() 缩放，正文 16px/1.9；九针格 3×3 → 2 列；传承表改单列。
- 无横向滚动；`overflow-x: clip`。
