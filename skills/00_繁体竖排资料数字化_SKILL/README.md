# 繁体竖排资料数字化 Skill

把繁体中文、竖排右起的传统书籍 / 讲义（扫描 PDF、内嵌图 docx、Word97 `.doc`）转成可检索、带目录与分卷锚点的纯文本。

## 这个仓库是什么

- **`SKILL.md`** —— 方法论核心：先判断源文件「有无文本层」，有就直接提取（零转录误差），没有才用视觉模型逐页转录（右→左、上→下）。覆盖清洗、目录、分卷、锚点全流程，附硬规则与验收清单。
- **`organize_template.py`** —— 整理脚本模板：把「带 `【第N頁】` 标记的裸文本」清洗成整理版 + 独立目录 + 按卷拆分文件（每卷带可点击小目录与篇题锚点）。换书只改顶部几个常量。
- **`tools/`** —— 三个已验证的辅助脚本：
  - `ole2_extract.js`：最小 OLE2/CFB 读取器（Word97 `.doc` 文本层手动提取用）
  - `render.js`：PDF 逐页渲染成图（图片型源转录前用）
  - `assemble.js`：多标记样式拼接 + 缺页诊断

## 怎么用

1. 读 `SKILL.md` 的「〇、边界」和「一、何时启用」，先判定走路径 A（提取）还是路径 B（视觉转录）。
2. 得到「带 `【第N頁】` 标记的裸文本」后，把 `organize_template.py` 放到源稿同目录，按书改顶部常量，运行：

   ```powershell
   & "C:\Users\HUAWEI\AppData\Local\Programs\Python\Python312\python.exe" organize_template.py
   ```

> 本仓库由真实活件经验归纳：韦千里《千里命稿》（`.doc` 有文本层）、
> 《九灵铁经·气功针经合璧》与《回到你的内在权威》（扫描 / 内嵌图，无文本层）。

*数字化只做搬运与结构化，不做校勘与润色；原稿字误一律保留。*
